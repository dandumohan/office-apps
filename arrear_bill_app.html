Run this SQL once in the Supabase SQL editor (safe to re-run):

create table if not exists pay_drawings(
 id uuid primary key default gen_random_uuid(),
 cfms_id text, emp_hrm_id text, pay jsonb, ded jsonb, emp jsonb,
 created_at timestamptz default now());
create table if not exists arrear_bills(
 id uuid primary key default gen_random_uuid(),
 emp_hrm_id text, cfms_id text, payments jsonb, deductions jsonb, net_payable numeric,
 arrear_periods jsonb, total_arrear numeric, created_at timestamptz default now());
alter table arrear_bills add column if not exists pay_id uuid;
alter table arrear_bills add column if not exists details jsonb;
alter table pay_drawings enable row level security;
alter table arrear_bills enable row level security;
drop policy if exists "open" on pay_drawings;
drop policy if exists "open" on arrear_bills;
create policy "open" on pay_drawings for all using(true) with check(true);
create policy "open" on arrear_bills for all using(true) with check(true);
notify pgrst, 'reload schema';

Arrear calculation (current bill)

Whole rupees. Basic = Basic Pay ÷ days in month × arrear days. DA/HRA = arrear Basic × %. Other pay heads = value entered (blank = pay drawing amount) ÷ days in month × arrear days. Deductions = amount typed for the period (blank = 0; ⇩Ded fills the pay drawing amounts); CPS employees get 10% of (arrear Basic + arrear DA) automatically. DA/HRA % default to the % set in Pay Drawing Particulars.

4. Bill Generation & Preview

Pay Difference Bill —

Each batch has one Already drawn pay and one To be drawn pay (for DA/HRA enter a % to calculate from Basic Pay) and as many periods as needed — the difference is applied to every period and all heads are summed across batches. Difference per head × period: if the unit is Days = difference ÷ 31 × days; if Months = difference × months. All amounts are rounded to whole rupees. Name, designation, office and signature come from Employee Details in the other tab.

Current bill

Reads either a table (columns: from, to, unit, To be drawn, Already drawn, DA %, HRA %, IR %) or “Pay Bill” blocks (From … to … – n months/days, Pay, D.A., HRA, Addl.HRA, CCA, Dhobi, Risk Allowance, IR with To be drawn / Already drawn) and adds them to this employee's bill, grouping periods with the same Already drawn / To be drawn Basic Pay into one batch (each period keeps its own DA % / HRA % / IR %; only a period whose other pay heads differ gets its own pay particulars).
