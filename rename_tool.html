Rename Console
mode: —

SF_CTR file renamer

Point this at a folder, set a naming template, then sort files into up to three subject compartments and drag them between compartments as needed. Applying renames each file, creates (or reuses) its subject folder, and moves it there.

1Naming template
Tokens: {YEAR} {MONTH} {SUBJECT} {NAME} {EXT} {COUNTER}
Each compartment is its own root folder — M1, M2, M3 — created on disk if it doesn't exist yet. Files sorted into a compartment move into a subject-named folder underneath it, e.g. /M1/Invoices/, and that subject also fills the {SUBJECT} token in the filename.
2Choose the folder to watch
Open the folder that contains the files to rename
Everything happens locally in your browser — nothing is uploaded.
Auto-watch this folder off
3Sort files & commit
Sort files into a box Move files between boxes freely — this is just a preview. Nothing is renamed or moved on disk until you commit.
